# Tally

他の家計簿からの明細取り込みと手入力で使える、日本語のローカル家計簿です。期間を選べるダッシュボード、収入・支出のツリーマップ、カテゴリ別の高額順、年間ヒートマップ、予算管理を備えています。

## 使う

- **ブラウザ版**：[単体HTML](<index.html>) をダウンロードし、EdgeまたはChromeで開いてください。GitHubのファイル表示はソースのプレビューです。Pagesのサイトではそのまま操作できます。
- **WindowsのSQLite版**：リポジトリをダウンロード・展開し、[起動スクリプト](<Start-SQLite.cmd>) を実行します。Python 3.8以上が必要です。[SQLite版の説明](<SQL-NOTES.md>)を参照してください。
- 操作手順はアプリ内の「使い方」、または[ガイド](<使い方.txt>)にあります。

## 他の家計簿から取り込む

「データ管理」→「インポート」で取り込み元を選びます。PayPay、マネーフォワード ME、Zaim、Tallyの明細CSVに加え、列を指定する汎用CSV・TSV（カンマ／タブ／セミコロン）、円建ての銀行・カードのOFX/QFX、QIFに対応します。書き出し方：[マネーフォワード MEの公式ガイド](https://support.me.moneyforward.com/hc/ja/articles/49505374073497) ／ [Zaimの公式ガイド](https://content.zaim.net/manuals/show/37)。全形式でプレビュー後にチェックした明細だけを追加します。元アプリ・バージョンによって列構成は異なります。PDFや残高・集計表は対象外です。異なるサービスをまたぐ同一支払いは自動で統合しません。

## データの保存先

Pagesが配信するのはアプリ本体だけです。静的なブラウザ版は明細をGitHubや外部サービスに送信せず、ブラウザ内に保存します。SQLiteのサーバーはPages上では動きません。

ファイル版から公開サイトに移っても、これまでの明細は自動では移りません。「データ管理」→「端末引き継ぎ用にエクスポート」（旧版は「バックアップを保存」）で取得したJSONを、新しいサイトの「バックアップから復元」で選んでください。明細に加えて予算・目標・カテゴリ・色・分類ルール・表示設定を引き継げます。表計算用CSVに設定は含まれません。復元は全件置換です。**バックアップやPayPayのCSVはGitHubにアップロードしないでください。**

ブラウザの保存領域はオリジン（スキーム・ホスト・ポート）単位です。同じ `ユーザー名.github.io` にある他のPagesサイトとはパスだけでは分離されません。信頼できないアプリと同居させる場合は専用オリジンを使ってください。サイトデータの消去で明細も消えるため、定期的なバックアップを推奨します。

## ビルドと公開

Node.jsで次を実行します。パッケージのインストールは不要です。

```sh
node build.cjs
```

[単体HTML](<index.html>) と [Pages版](<docs/index.html>) が同じ内容で生成されます。GitHubの **Settings → Pages → Deploy from a branch → `main` / `/docs`** を選ぶ構成です。編集後は再ビルドして生成物も一緒にコミットしてください。CI用の秘密情報や追加のGitHub Actionsワークフローは不要です。
